# Human Sandbox
Sandbox game for Linux, made with raylib and box2d.

## Prerequisites
- raylib
- box2d

## Installation
Build executable with `make` command:
```bash
$ make
```
then execute:
```bash
$ ./sandbox
```

## Controls
- spawn item: `E` (flipped `Q`)
- undo spawn: `Z` (`SHIFT+Z` to clear all)
- move camera: middle click and move mouse
- measure: left click and move mouse
- pause time: `SPACE`
- rotate: `A` or `D` (hold `SHIFT` to increase or `CTRL` to decrease speed)
- open/close sidebar: `TAB`
